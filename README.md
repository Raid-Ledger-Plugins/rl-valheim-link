# RL Valheim Link

A BepInEx 5 mod for Valheim (client + dedicated server) that exports a player's character
summary, explored map and pins, and the item name/icon catalogue, and pushes them to a
[Raid Ledger](https://github.com/sjdodge123/Raid-Ledger) instance. Story **ROK-1834**; design
background ROK-1799; wire contract ROK-1829; ingest endpoint ROK-1833 (merged 2026-10-18).
Thunderstore package: `RaidLedger-ValheimLink`.

```
player client ──(chunked routed RPC)──► dedicated server ──(HTTPS, per-server bearer token)──► Raid Ledger
   captures on profile save              validates, dedupes, uploads                 ingest (ROK-1833)
```

**Raid Ledger owns the wire format.** `contract/v1/` is a pinned, verbatim copy of
`packages/contract/valheim-link/v1/` (see [`contract/PIN.md`](contract/PIN.md)); this repo never
changes it, validates every message against it, and CI fails when the copy drifts from upstream.

## Build and test

Needs .NET SDK 9 and Node 22+. No game files are required: the plugin compiles against the
community `ValheimGameLibs` NuGet package; set `VALHEIM_INSTALL` to use your own install instead
([`docs/reference-assemblies.md`](docs/reference-assemblies.md)).

```bash
dotnet test tests/RlValheimLink.Contract.Tests              # validator + encoders against the pinned fixtures
dotnet build src/RlValheimLink/RlValheimLink.csproj -c Release
cd tools/contract-check && npm ci && node validate.mjs ../../fixtures && ./drift-check.sh
cd tools/mock-ingest && npm ci && npm test && npm start     # local ingest on :8787
```

Output: `src/RlValheimLink/bin/Release/net472/RlValheimLink.dll` + `RlValheimLink.Contract.dll` +
`RlValheimLink.Core.dll` → copy all three to `BepInEx/plugins/RlValheimLink/` on the client and the server.

## Config

`BepInEx/config/RaidLedger.ValheimLink.cfg` (created on first run). Server: `[RaidLedger]
BaseUrl`, `ServerToken`, `ServerId`; upload cadence under `[Upload]`. Client: `[Client] OptOut`
(per-player opt-out), `SendCharacter`, `SendMap`. Full table in `docs/design.md` §8.

## Fixtures and CI

- `contract/v1/fixtures/` (golden + invalid) come from Raid Ledger and are never edited.
- `fixtures/` is this mod's own serialised output for synthetic captures (no real Steam ids,
  names or seeds) and is regenerated by the tests (`RLVL_WRITE_FIXTURES=1`).
- CI (`.github/workflows/ci.yml`): `contract-drift` (pin vs upstream main), `fixtures` (ajv +
  C# validator + mock-ingest; **always runs**), `build` (compiles when the game assemblies
  restore; records in the job summary whether it did).
- Release (`release.yml`): a `v*` tag builds the Thunderstore zip `RaidLedger-ValheimLink-<version>.zip`
  and attaches it to a GitHub release. Thunderstore package: namespace `RaidLedger`, name `ValheimLink`
  (`thunderstore/` holds the manifest, icon and the Thunderstore README).
